Task 2: MaybeUninit UB Fix Evidence
====================================
Date: 2026-02-20

## Changes Made

### 1. MoveBuffer (src/movegen.rs:22)
BEFORE: data: unsafe { std::mem::MaybeUninit::uninit().assume_init() }
AFTER:  data: [Move::none(); MAX_MOVES]

Rationale: Move is Copy, Move::none() is const fn returning Self { data: 0 }.
[Move::none(); 256] is safe, zero-cost (same as zeroed memory), no UB.
MoveBuffer.len tracks valid entries — slots beyond len are never read.

### 2. spin_set (src/movegen.rs:93-97)
BEFORE: if CHECK_SPIN { [[[0u64; ...]; ...]; ...] } else { unsafe { MaybeUninit::uninit().assume_init() } }
AFTER:  [[[0u64; SPIN_NB]; ROTATION_NB]; COL_NB]  (unconditional zero-init)

Rationale: Plain integers. Zero-init is trivially safe. The conditional
was a micro-optimization to skip zeroing when CHECK_SPIN=false, but the
compiler optimizes this away — dead stores to spin_set are eliminated
when CHECK_SPIN=false since all reads are behind `if CHECK_SPIN` guards.
